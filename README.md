## Projects

### [Kernex](https://github.com/baselanaya/Kernex)
[![Rust](https://img.shields.io/badge/Rust-1.75+-orange?style=flat-square&logo=rust&logoColor=white)](https://github.com/baselanaya/Kernex)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow?style=flat-square)](https://github.com/baselanaya/Kernex/blob/main/LICENSE)
[![Platform](https://img.shields.io/badge/platform-linux%20%7C%20macOS-lightgrey?style=flat-square)](#)
[![Release](https://img.shields.io/badge/release-v0.1.0-green?style=flat-square)](https://github.com/baselanaya/Kernex/releases/tag/v0.1.0)

Zero-trust kernel-level execution hypervisor for AI agents. Wraps any agent process with OS-level syscall interception using Linux Landlock LSM + seccomp BPF — no VMs, no daemons, one binary. Sandboxed, auditable, minimal surface.

> `kernex run -- python my_agent.py`

**Stack:** Rust · Landlock LSM · seccomp BPF · macOS Endpoint Security · Unix Domain Socket IPC

### [Mercer](https://github.com/baselanaya/Mercer)
[![Python](https://img.shields.io/badge/python-3.11+-3776AB?style=flat-square&logo=python&logoColor=white)](https://github.com/baselanaya/Mercer)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow?style=flat-square)](https://github.com/baselanaya/Mercer/blob/main/LICENSE)
[![Exec Accuracy](https://img.shields.io/badge/exec_accuracy-74%25-22c55e?style=flat-square)](#)
[![Backend](https://img.shields.io/badge/FastAPI-backend-009688?style=flat-square&logo=fastapi&logoColor=white)](https://github.com/baselanaya/Mercer)

Text-to-SQL for messy production schemas. Converts plain English to accurate SQL through a 6-stage agentic pipeline — entity retrieval, schema linking, query decomposition, multi-candidate generation, execution scoring, and taxonomy-guided correction. Runs fully on a consumer GPU (8 GB VRAM) with no vector database required.

**Stack:** Python · llama.cpp · Qwen2.5-Coder-7B · Triton GPU kernels · FastAPI · React · Redis · SQLAlchemy

### [Cynosure](https://github.com/baselanaya/Cynosure)
[![Python](https://img.shields.io/badge/python-3.11+-3776AB?style=flat-square&logo=python&logoColor=white)](https://github.com/baselanaya/Cynosure)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow?style=flat-square)](https://github.com/baselanaya/Cynosure)
[![Status](https://img.shields.io/badge/status-active_development-blue?style=flat-square)](#)
[![Exchange](https://img.shields.io/badge/exchange-OKX-black?style=flat-square)](#)

Fully local, autonomous AI trading system for OKX perpetual swaps — crypto majors, commodities, and US equity index perps. Runs 24/7 with no cloud LLM dependency. A local Qwen3.5-4B synthesizer reads a pre-computed expert signal brief (~500 tokens) and outputs structured JSON trade decisions; all risk logic, position sizing (Kelly Criterion), and execution are deterministic Python.

**Stack:** Python · Qwen3.5-4B · Ollama · TimesFM 2.5 · OKX MCP · DuckDB · APScheduler · Textual TUI
